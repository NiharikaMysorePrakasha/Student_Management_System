# Student_Management_System

A full-stack web application developed to automate and manage academic operations such as course registration, subject management, and student information editing. Designed by a collaborative student team, the system ensures a smooth and secure experience for both administrators and students within an academic institution.

## 📘 Project Abstract

The School Management System is a web-based portal that facilitates the efficient management of courses, subjects, and student data in an educational setting. The platform supports critical academic workflows such as student registration, course enrollment, and administrative updates. Built with PHP and MySQL on the backend, and HTML/CSS/JavaScript on the frontend, the system bridges the gap between administration and student services.

This project aimed to eliminate manual processes, reduce administrative workload, and provide a centralized platform to manage academic records securely. Our team focused on front-end UI design and backend integration, ensuring all modules communicate effectively to support real-time data processing.

## 🧭 Project Overview

This system includes the following modules:

- **Authentication System:** Enables secure login and registration for users.
- **Student Dashboard:** Allows users to view and manage registered courses.
- **Course Management:** Admins can create, edit, and delete course offerings.
- **Subject Management:** Subjects can be added, updated, or removed.
- **Student Profile Editing:** Admins can update student details.
- **Course Availability Checking:** Students can see real-time availability of courses.
- **Session and Security Management:** Ensures valid session handling and logout.

Each module is backed by a MySQL database with structured tables for courses, students, and user credentials.

## 📊 Datasets

- **User Table:** Stores credentials and roles (admin/student)
- **Courses Table:** Contains all course-related data (course ID, name, availability, credits)
- **Subjects Table:** Includes subject details linked with courses
- **Student Table:** Student information like ID, name, email, registered courses
